# Love in Pixels

Private pastel pixel-art puzzle adventure (Adventure mode only). Plain HTML/JS, no build step.

- `index.html`  the playable game (character select, Chapter 1 so far)
- `assets/`     photos, videos, music, program, icon (web-safe file names, duplicates removed)
- `docs/`       DEVELOPER_BUILD_SPEC.md (current source of truth), original handoff and design docs
- `extras/`     standalone letter page + PDF
- `legacy-prototype/`  earlier prototype, kept for reference only

Run locally: `python3 -m http.server 8000` then open http://localhost:8000
Keep hosting private: the media and letter are personal. Do not publish to a public repo or public Pages site.
